UP Entregas v1.8.0 — publicar pelo Termux

1) Depois de baixar este ZIP para Downloads:

rm -rf ~/UpEntregas-v18
mkdir -p ~/UpEntregas-v18
unzip ~/storage/downloads/UP-Entregas-v1.8.0-VISUAL-PROFISSIONAL-GitHub.zip -d ~/UpEntregas-v18
cd ~/UpEntregas-v18

2) Conferir se a raiz está certa:

ls -la

Você deve ver app, .github, build.gradle, settings.gradle etc. diretamente aqui.

3) Enviar ao GitHub:

rm -rf .git
git init
git branch -M main
git remote add origin https://github.com/Rodriguesac/UpEntregas.git
git add .
git commit -m "UP Entregas v1.8.0 - visual profissional"
git push -u origin main --force

4) Gerar APK:

gh workflow run "Gerar APK UP Entregas" --repo Rodriguesac/UpEntregas

gh run list --repo Rodriguesac/UpEntregas --workflow "Gerar APK UP Entregas" --limit 3

5) Quando estiver SUCCESS, baixar:

mkdir -p ~/storage/downloads/UP-Entregas-v18-APK
gh run download --repo Rodriguesac/UpEntregas --dir ~/storage/downloads/UP-Entregas-v18-APK
find ~/storage/downloads/UP-Entregas-v18-APK -type f
