UP ENTREGAS V2.1 — PUBLICAÇÃO PELO TERMUX

1) Descompactar:
rm -rf ~/UpEntregas-v21
mkdir -p ~/UpEntregas-v21
unzip ~/storage/downloads/UP-Entregas-v2.1.0-CENTRAL-ROTAS-GitHub.zip -d ~/UpEntregas-v21
cd ~/UpEntregas-v21

2) Enviar ao GitHub:
git init
git branch -M main
git remote remove origin 2>/dev/null || true
git remote add origin https://github.com/Rodriguesac/UpEntregas.git
git add .
git commit -m "UP Entregas v2.1.0 - Central e rotas multiplas"
git push -u origin main --force

3) Gerar APK:
gh workflow run "Gerar APK UP Entregas" --repo Rodriguesac/UpEntregas

gh run list --repo Rodriguesac/UpEntregas --workflow "Gerar APK UP Entregas" --limit 3

4) Quando aparecer SUCCESS, baixar:
mkdir -p ~/storage/downloads/UP-Entregas-V21
gh run download --repo Rodriguesac/UpEntregas --dir ~/storage/downloads/UP-Entregas-V21
find ~/storage/downloads/UP-Entregas-V21 -type f

IMPORTANTE — regras Firestore:
A rota múltipla V2.1 precisa das regras incluídas neste projeto em firestore.rules.
Se você já usa Firebase CLI no Termux, dentro desta pasta:
firebase deploy --only firestore:rules --project rodrigues-d6566

Se o comando firebase não existir, não instale nada às cegas: publique as regras pelo Console Firebase ou configure o Firebase CLI primeiro.
