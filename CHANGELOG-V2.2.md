# UP Entregas V2.2.0 — Sincronia de estados

- Protocolo operacional UP V3.
- Rota fica aberta para complemento somente antes da retirada.
- Publica `upOpenRouteId` para Gestor/Central reconhecerem a rota aberta.
- Ao retirar, fecha complemento imediatamente e muda o foco para o cliente.
- Tela na loja não continua oferecendo navegação até a loja.
- Complemento +1 funciona também quando a missão original começou como corrida individual.
- Mapa/título/ação principal passam a seguir o mesmo estado canônico.
