UP ENTREGAS V1.9 — PUBLICAR PELO TERMUX

1) Extraia o ZIP e entre na pasta:
   rm -rf ~/UpEntregas-v19
   mkdir -p ~/UpEntregas-v19
   unzip ~/storage/downloads/UP-Entregas-v1.9.0-FOCO-NA-ENTREGA-GitHub.zip -d ~/UpEntregas-v19
   cd ~/UpEntregas-v19

2) Suba para o repositório:
   git init
   git branch -M main
   git remote add origin https://github.com/Rodriguesac/UpEntregas.git
   git add .
   git commit -m "UP Entregas v1.9.0 - foco na entrega"
   git push -u origin main --force

3) O push já dispara o workflow. Confira:
   gh run list --repo Rodriguesac/UpEntregas --workflow "Gerar APK UP Entregas" --limit 3

4) Quando estiver success, baixe o artefato:
   mkdir -p ~/storage/downloads/UP-Entregas-v19
   gh run download --repo Rodriguesac/UpEntregas --dir ~/storage/downloads/UP-Entregas-v19

IMPORTANTE SOBRE ATUALIZAÇÃO:
A primeira V1.9 pode exigir uma última desinstalação da versão anterior por causa da assinatura antiga.
A partir da V1.9 o workflow preserva a mesma chave de assinatura de debug entre compilações.
