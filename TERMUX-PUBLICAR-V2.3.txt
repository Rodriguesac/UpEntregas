UP ENTREGAS 2.3.0 — PUBLICAR PELO TERMUX

1) Baixe UP-Entregas-v2.3.0-MATERIAL-NATIVE-GitHub.zip para Downloads.

2) Rode:

rm -rf ~/UpEntregas-v23
mkdir -p ~/UpEntregas-v23
unzip ~/storage/downloads/UP-Entregas-v2.3.0-MATERIAL-NATIVE-GitHub.zip -d ~/UpEntregas-v23
cd ~/UpEntregas-v23

./scripts/validar-v230.sh

git init
git branch -M main
git remote remove origin 2>/dev/null
git remote add origin https://github.com/Rodriguesac/UpEntregas.git
git add .
git commit -m "UP Entregas v2.3 - Material Native"
git push -u origin main --force

gh workflow run "Gerar APK UP Entregas" --repo Rodriguesac/UpEntregas

gh run list --repo Rodriguesac/UpEntregas --workflow "Gerar APK UP Entregas" --limit 3

3) Depois que aparecer ✓, baixe o artifact:

gh run download --repo Rodriguesac/UpEntregas --dir ~/storage/downloads/UP-Entregas-v23-APK
